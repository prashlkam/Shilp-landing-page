Shilp (शिल्प) is a Hindi programming language whose semantics are identical to Python — a thin, token-level translation layer over CPython. Write in Devanagari, and every Python feature just works.

विशेषताएँ · Features

Familiar power, in your own script

Because the mapping is one-to-one and reversible, Shilp doesn't reimplement Python — it is Python, spoken in Hindi.

🧩

Full Python parity

Classes, generators, decorators, async/await, pattern matching — all of it works, because CPython compiles the translated tokens directly.

🔤

Native Devanagari

Hindi keywords and Devanagari numerals convert seamlessly. Write अगर, हर, वर्ग — read like Python underneath.

🪶

Thin translation layer

A token-level pass maps Hindi to Python while preserving line numbers — no heavy interpreter, no runtime penalty.

📦

Any Python library

Import NumPy, requests, Django — the whole ecosystem imports normally. Multi-file .shilp modules work too.

🩺

Hindi error messages

Tracebacks appear in Hindi with the original source lines preserved, so debugging stays in your language.

🎨

Editor support

VS Code syntax highlighting plus phonetic input snippets — type in roman, get Devanagari keywords instantly.

generated.py
def greet(name):
    if name == "":
        return "नमस्ते, दुनिया!"
    return f"नमस्ते, {name}!"

for person in ["अर्जुन", "प्रिया", "कबीर"]:
    print(greet(person))

प्रारंभ · Quickstart

Up and running in seconds

If you have Python 3.12+, you already have everything you need.

1

Install with pip

pip install shilp
2

Write your first program

छापो("नमस्ते, दुनिया!")
3

Run it

shilp program.shilp

CLI commands

  • shilplaunch the interactive REPL
  • shilp program.shilpexecute a program
  • shilp anuvad program.shilpshow the generated Python
  • shilp jaanch program.shilpvalidate syntax only
